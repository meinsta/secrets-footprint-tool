📱 Quick Setup Guide

  1. Get Admin Link: Check deployment logs for invite link
  2. Open Teleport: Click "Open Teleport Web UI" above
  3. Accept SSL Warning: Self-signed cert (normal for IP access)
  4. Use Invite Link: Paste the admin invite URL
  5. Setup TOTP: Scan QR code with Google Authenticator
  6. Login: Use username + TOTP code
  7. Run Assessments: Start scanning for secrets!
🚨 SSL Certificate Warning:
You'll see a browser warning about the SSL certificate - this is normal when using IP addresses. Click "Advanced" → "Proceed to SERVER_IP" to continue safely.
